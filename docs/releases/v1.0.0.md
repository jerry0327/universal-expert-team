# Universal Expert Team v1.0.0

## 繁體中文

Universal Expert Team 首次公開發布。它是一套可攜的 AI 團隊協作 Skill：依任務設計分工，讓工作者在授權範圍內完成實質工作，再以證據和適當的獨立審查判斷是否完成。

此版本提供：

- 預設一次完整交付；明確要求時，針對指定範圍反覆驗收修正。
- 動態專業分工、依賴排程、寫入責任、取消與續作規則。
- 獨立審查、交叉查核、異議裁決與可驗證的停止條件。
- 隨包提供的通用執行指引；不需要私人帳號的配套 Skill。
- 繁體中文與英文首頁、安裝指南、使用範例及 MIT 授權。

下載 **universal-expert-team-v1.0.0.zip**，並依[安裝指南](https://github.com/jerry0327/universal-expert-team/blob/v1.0.0/docs/installation.md)使用。`SHA256SUMS` 提供檔案雜湊，可檢查下載是否完整。

Skill 本身不會新增模型、子代理工具或外部服務權限。實際協作能力仍由使用環境決定；能力不足時必須如實回報。驗證方式與範圍見[驗證說明](https://github.com/jerry0327/universal-expert-team/blob/v1.0.0/docs/validation.md)。

## English

The first public release of Universal Expert Team: a portable skill for designing real AI teams around the work, delegating complete authorized tasks, and evaluating completion with evidence and appropriate independent review.

This release includes dynamic team design, single complete delivery, scoped iterative review and repair, work ownership, cancellation and recovery guidance, portable runtime instructions, bilingual documentation, and an MIT license.

Download **universal-expert-team-v1.0.0.zip** and follow the [installation guide](https://github.com/jerry0327/universal-expert-team/blob/v1.0.0/docs/installation.md). Use `SHA256SUMS` to check download integrity.

This is an instruction package, not an agent runtime or a grant of access. Actual delegation depends on the host's exposed tools. See the [validation guide](https://github.com/jerry0327/universal-expert-team/blob/v1.0.0/docs/validation.md) for the distinction between structural checks, behavioral evidence and untested environments.
