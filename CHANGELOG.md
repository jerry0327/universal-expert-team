# Changelog

## 1.0.0 — 2026-10-28

First public edition of Universal Expert Team.

- Design expert teams from the requested deliverables, dependencies and actual tool capabilities.
- Support single complete delivery, explicit iterative review and repair, and mixed scopes.
- Delegate complete authorized work with clear ownership and acceptance criteria.
- Separate real workers, independent evidence, scenario evaluations and unverified capabilities.
- Include portable runtime guidance without requiring private account skills or a particular device.
- Provide Traditional Chinese and English introductions, installation guidance, examples, validation and reproducible release packaging.

This release packages instructions for a compatible agent host. It does not provide an agent runtime, credentials or model access.
